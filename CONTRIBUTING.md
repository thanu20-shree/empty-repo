# Contributing Guidelines

Thank you for your interest in contributing to this project!  
To keep the project organised and easy to maintain, please follow these rules:

1. Create a new branch for every feature or bug fix.
2. Use meaningful and descriptive commit messages.
3. Do not make changes directly on the main branch.
4. Submit a Pull Request and wait for review before merging.
5. Follow the existing folder structure and coding conventions.
6. Update documentation when necessary.
